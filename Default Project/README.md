# MeetFlow AI — Project Workspace

This workspace contains the **MeetFlow AI** project (meeting-to-execution AI agent) and its prompt-engineering evidence.

## 📁 Structure

| Path | Description |
|------|-------------|
| [`meetflow_ai/`](meetflow_ai/) | The website — full source code, run instructions, and [`README.md`](meetflow_ai/README.md) |
| [`PROMPTS.md`](PROMPTS.md) | Prompt engineering documentation: the 5-part initial prompt, prompt log, refinement examples, AI tool contributions, techniques checklist |
| [`evidence/`](evidence/) | Evidence for the 3 AI tools used (ChatGPT, Claude, Google Gemini): prompts, outputs, screenshots |
| [`docs/`](meetflow_ai/docs/) | Screenshots referenced by the README |
| `start_site.ps1` | One-click launcher (starts backend + frontend + opens browser) |

## 🤖 AI Tools Used (3)
1. **ChatGPT** — initial website generation
2. **Claude** — chatbot 502 bug fix
3. **Google Gemini** — AI Meeting Scheduler feature

## 🚀 Quick Start
See [`meetflow_ai/README.md`](meetflow_ai/README.md) §7 (Run Locally), or run `.\start_site.ps1`.
